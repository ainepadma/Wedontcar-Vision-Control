# 环岛识别与诊断（0.26.0）

本轮删除按真实边界角度强制回中300ms的整条动作链。角度仍可显示为O值用于诊断，但不改变路径或舵机输出。速度、舵机端点/中位、P/D、前瞻、按键和电机保护参数未改。

## 四次补线与内部阶段

用户的四次补线不是代码的S1至S4。内部S1/S2为入口封口，S3/S4为引导入环，S5为右侧横口补线，S6等待最终出口，S7为最终出环。

- 第三次：在当前帧右侧边界上寻找有上下双臂支持的内向尖角，沿用向左上真实黑色边界连接的方法；漏检时保留原断点候选。不改变入口/270通用角点。成对近端边界不再独自使S5提前结束。
- S5观察到横口后，横口补线消失、外侧边界连续达到3张新帧，且已见横口下降到近处或新的有效内侧出口V，才能进入S6。快车漏过横口的近端位置可用新的出口几何证明横口已过；从未见过第三次横口不能跳过。
- 第四次：当前内侧V连接同侧最下方实际黑色边界。左旋补左侧，右旋镜像补右侧。没有全宽白带/固定角度前提；补线顶点以上不参与该路线中线计算。
- S6解锁后可立即使用当前第四次候选，连续3张新帧确认进入S7；每张帧最多推进一级。S7不再选回第三次补线。临时漏检仅保持该出口同向补线最多120ms，不续期；过期返回无效。
- 正常道路满足置信度、全局/近场/底部一致性条件且至少8张新帧、200ms稳定后完成。完成后至少600ms、10张稳定道路帧才重新开放入口识别。这些时间仅用于视觉去抖与交接，不强制舵机直行。

## 屏幕与日志

C为实际控制、P为停机手推预览。S为内部阶段，G为实际补线编号；G17/G18第三次，G19/G20为S6延续候选，G21/G22第四次。H为短时保持，N普通路径，G当前补线，U无效。当前固件不生成T或ring_source=4；旧版CSV仍可能含4，导出器保留向后兼容。

CSV仍为33列，前25列不变，追加字段：ring_stage、ring_guide、ring_source（0=N，1=G，2=H，3=U）、ring_direction、bridge_seen、bridge_passed、exit_armed、transition_frames。bridge_seen为已经看到第三次横口，bridge_passed为横口已到近处，exit_armed为横口通过后已开放最终出口识别。方向1为内侧左，-1为内侧右。数据来自实际控制ISR；预览不作为运行证据。日志1MiB/50Hz/56字节不变。
