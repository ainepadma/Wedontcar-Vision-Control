1. 本轮p3：准备第三次，横边尚未平缓，不拉第三次线，也不进S7。
2. 本轮p4：A已识别且上方主路边界平缓，从A点向左上真实黑边连接，右侧开始第三次补线。其后p1继续。
3. 本轮p2：横跨主路的宽白带到达画面中部。此帧仅锁存separator_seen，仍右侧补线；记录本圈保留，不需要白带持续出现。
4. 后续新帧出现出口侧向下V或_|角，才允许第四次。原三帧确认不增加；斜V和一臂近水平的角均允许。第四次仍连接该角与同侧底部实际黑边，按中线转向。

用户四次补线与内部七阶段不是同一编号：S5第三次，S6记录分隔后等待第四次，S7第四次；G17/G18、G19/G20均为第三次右/左侧延续，G21/G22为第四次。白带当帧不选G21/G22。不存在‘出口候选有效即可证明第三次已过’的捷径。

## 判据

第三次主路上边界左侧约5%至36%宽度段拟合dy/dx，绝对值≤0.33，并有A/横口角证据；右旋镜像。避免用曲线上左右抵消后的整体斜率或A边几像素小台阶代替。

分隔白带以连续白段≥95%宽、厚≥5%高、中心达到45%高识别，容许少量边缘黑列。p2最大白段299/304，原全像素白判断会漏掉。只在第三次已拉线后锁存。

最终角点独立于入口V检测；轮廓支持稍加长，至少一臂明显向上、另一臂可平，要求尖角上方黑下方白、位置对应实际边界，排除<的同侧双臂、浅台阶及图像边缘伪角。原角点找回和120ms有界保持、正常道路稳定交接与重入冷却沿用。
