# 0.25.0 环岛出口外侧边界角、短时直行与稳定交接

本版针对“刚出环又拐回原环岛”：保留S6/S7反侧A点60°补线，在S7测量真实外侧边界角度，符合参考照片方向时执行一次300ms回中直行；随后验证普通道路的交接条件，再冷却重入。按键、舵机端点/中位、P/D、速度数值及PWM上限不变，强制回中是新增动作。实际验证见CHANGELOG；尚未完成本版实车验收，不能据此认定已消除回环。

## 2026-11-05 最新实车反馈：出环仍有偏转

用户报告当前出环没有沿直线行驶，仍有一定偏转，直线出环验收未通过。本轮未取得同趟CSV、连续画面或车端FW读数；偏转方向/幅度、O角度、T是否触发/持续多久，以及偏转时所在阶段均待核实，不先归因于舵机中位或300ms参数。

后续按同一时段证据区分：

1. 没出现T：检查S7/A1、实测外侧角有效位、52°～68°范围、3帧确认及当前路线置信度。
2. T期间：确认ring_source=4、servo10是否持续870；870只是指令，不能证明前轮物理居中或车身无侧偏。
3. T提前结束：检查frame_age_ms、真实路线有效性与保护/停车记录。
4. T到期之后：检查是否恢复G21/G22，或普通路线/近场/底部交接使车再次偏转。

本轮只记录现象和待核验项，不修改算法、标定、速度或时间参数。尚无证据证明300ms直行确实触发，也不能将此次偏转直接记为已经二次进环。

## 当前S6/S7规则

1. 对当前二值帧直接扫描，包括第0列和最后一列；一行每个像素都非零才算全白。连续行数达到图像高度的5%（向上取整）才构成白带。参数在`demo/user/inc/ring_corner.h`：`RING_EXIT_WHITE_BAND_PERCENT`，范围1～100。当前154行至少8行；一行有一个黑像素也会截断连续计数，不改二值图、不增加降噪或清黑。
2. 多条白带同时存在时仍选择最靠近画面底部的合格白带，但白带坐标不再决定补线起点。S6首次获得可用白带补线就使用G19/G20，不等待转换确认；连续3张不同帧同时具备白带和有效补线后进入S7，设置A1。缺少白带、缺少合格A点或生成路径无效时，S6沿用普通路线且不推进。
3. 左旋/内侧为左时补右边界，从右侧A点向左上延伸（反斜杠方向）；右旋/内侧为右时补左边界，从左侧A点向右上延伸（正斜杠方向）。两侧镜像。角度宏为`demo/user/inc/ring_corner.h`中的`RING_EXIT_LINE_ANGLE_DEG=60.0f`，相对原图竖直向上方向计角，满足`abs(dx)/abs(dy)=tan(60°)`，约为1.732；不是相对水平的60°，也不是舵机转角。可调范围为有限数值且`0<deg<90`，超出范围时不生成退出补线。屏幕缩放后的视觉角度不保证60°。
4. 起点必须使用当前帧的反侧`a[]`：左旋取`a[1]`，右旋取`a[0]`；要求`kind==RING_CORNER_A`、质量至少55、x/y为有限数且位于图内。该点代表下方边界向车道内凸出的A唇尖，不以breakpoint、白带底行、画面边缘或角点替代。延长线从A点向上按既定角度裁剪到图像边界，裁剪保留斜率；沿用现有路径有效性检查。没有合格A点时不生成新补线，不设旧锚点后备。
5. S7使用相同白带、A点及镜像补线规则（G21/G22），V点重找不能重新写入旧内侧补线。白带或A点暂失时，沿用已接受的同向S6/S7路线最多120ms，期限从最后一次真实有效补线计算；超时无效，不回退岔路普通中线。当前没有独立的单侧A点稳定追踪，120ms表示历史路线短时保持，不表示找到了当前帧A点。
6. S7新增下述角度触发的一次性直行。未触发或已结束时，白带消失、无入口/交叉特征、road_clear及当前普通路线有效且置信度≥65、|E|≤180、|H|≤120才允许试交接；有效近场也要求|E|≤180、|H|≤120，且与全局E不能在±40死区外反号；有效底部误差须|E|≤80。试交接期间保留S7，采用当前普通中线并关闭近场/底部覆盖，连续至少8张新帧且跨度≥200ms才完成。条件失败或帧间隔>150ms重新计数，重复帧不计。普通道路已稳定时可直接完成，不强制等待角度触发。
7. 完成时清零旧确认票，进入360冷却。至少600ms且连续10张满足上述交接条件的新道路帧后才重开入口识别；有旧路口干扰清零道路帧计数，解锁当帧不投入口票。下一圈仍需新的3帧入口确认；270保持原三帧规则。计时与视觉稳定不能证明真实行驶距离。
8. 旧的外侧路口已见/通过、恢复配对道路、新内侧V等条件不再控制S6→S7。S5及S5→S6未修改，若仍卡S5，本轮白带规则尚未接管。

## 真实外侧边界与300ms直行

照片IMG_20261105_222311中的目标是右侧赛道边界，不是舵机中位87°。根据拍屏粗估，边界与屏幕水平约成70°；原图304×154缩放为125×100，水平与竖直缩放比例不同，换回原图约为60°。这只是起始阈值估计，不是从该照片恢复的精确车载测量，也不是车身相对赛道的物理航向角。

- 每帧在原图高度55%～90%内，分别拟合左右真实逐行边界`x=k*y+b`，不读取虚拟补线。只取最长连续可靠段，至少8点且纵向跨度≥ceil(高度×20%)；相邻x跳变>max(2,宽/40)即分段。最大拟合残差≤min(3,max(1.5,宽×1%))像素，RMS≤该阈值一半。不跨缺口、触边代用点或分叉拼接拟合；当前帧失效即清有效位。
- `border_angle10`以原图水平为基准，`atan2(1,k)`得到0～180°：右侧60°、镜像左侧120°，竖直为90°。左旋用右侧原值；右旋用左侧的180°减原值，统一比较60°目标。不要与补线相对竖直60°混用。
- 仅360的S7且A1时可触发：有效真实外侧边界角连续3张新帧落在52°～68°，同时当前普通路径或S7补线路径有效且置信度≥45。错侧、反斜率、虚拟线、无效角度、重复帧不计数；不在S7不会回中。
- 触发后保持S7、来源T、G00，向控制器提供零偏差路线，并在输出端直接将舵机指令设为标定中位87°，清除旧滤波/D项/近场/底部脉冲。**这一回中动作不经过普通180°/s软件斜率限制**；硬件到达中位仍需时间，300ms不是实测直行距离。保持现有环岛速度上限，不额外加速；差速沿用360锁定时为零的现有逻辑。
- 定时从首次触发起算，后续匹配不续期；300ms到期结束。新鲜图像中的普通路线与S7路线同时无效/低置信度时提前取消；图像间隔>150ms取消，即使C14关闭也不会无限强制。停止优先，C13及电机独立保护不会被重启；C14关闭时取消直行本身不等于停车。
- 同次环岛只允许一次直行动作。结束后重新累计稳定道路交接条件，不能拿强制直行的时间冒充交接稳定时间。若仍看见有效白带/A点且道路尚未合格，会恢复G21/G22；300ms过短仍可能回环，需要看日志实测，不能靠盲目加长保证成功。

可调项均位于`demo/user/inc/ring_control.h`：

|宏|默认值|含义|
|---|---:|---|
|RING_EXIT_BORDER_TARGET10|600|原图外侧边界目标角，0.1°单位；600=60°|
|RING_EXIT_BORDER_TOLERANCE10|80|角度容差，80=±8°|
|RING_EXIT_STRAIGHT_CONFIRM_FRAMES|3|连续新帧确认数|
|RING_EXIT_STRAIGHT_MS|300|一次强制回中持续毫秒|
|RING_EXIT_SETTLE_FRAMES / RING_EXIT_SETTLE_MS|8 / 200|普通道路交接帧数和持续时间，须同时满足|
|RING_360_REARM_FRAMES / RING_360_REARM_MS|10 / 600|完成后的重入门控帧数和最短时间，须同时满足|

全白曝光或场外白地也可能满足白带特征；该特征仅用于已进入360的S6/S7，不用于冷态判入环。5%仍为白带厚度参数，60°为本次起始角度，实车阈值和方向效果待验证。A点与角度正确也不等于实际转向足够：控制仍使用现有中线误差、航向和控制器，须结合运行日志验证。

## 屏幕读法

运行时第二行示例：`C S6 G19 G A0`。

- `C`：实际控制状态快照；停车预览使用`P`，不能将预览推进当成实车状态。
- `S6`：七阶段中的第6阶段，直接读取corner_stage，不是合并后的ring_phase。
- `G19`：控制当前选择的补线编号；运行时不会因为显示帧不同或短时保持而错误显示G00。
- 来源字符：`N`普通中线，`G`当前补线，`H`历史补线短时保持，`U`无效路线，`T`一次性强制直行。
- S7第一行的`O060`表示当前同帧实测外侧边界角（镜像归一后、四舍五入到度）；`O---`表示无有效同帧角度。它取代该行的H显示，CSV仍保存heading。S7直行时显示`C S7 G00 T A1`和`360 S7 STRAIGHT`；停车P预览仅模拟状态，不驱动车辆。
- `A0/A1`：出口是否解锁（exit_armed），不是几何A点。
- 下一行示例：`360 S6 EXITWAIT`。S1 ENTRY、S2 PREIN、S3 INLOCK、S4 JOIN、S5 RING、S6 EXITWAIT、S7 EXIT。
- 同帧图像与控制快照不匹配、或使用H保持时，不把旧补线伪装成当前图像观测；S3没有当前补线时不绘制普通中线作为替代。故障/停车信息沿用原显示优先级。

|阶段|内侧为左的补线编号|内侧为右的补线编号|
|---|---:|---:|
|S1|9|10|
|S2|11|12|
|S3|13|14|
|S4|15|16|
|S5|17|18|
|S6|19|20|
|S7|21|22|

S3确认向S4转换期间，原有同向衔接允许S3选择G15/G16，因此编号不必始终与阶段一一对应。G0表示没有使用补线；结合N/U/T判断普通路线、无效或强制直行。S7合格普通路线的同帧中线允许显示，T期间不把普通中线画成实际控制轨迹。270补线仍为G1/G2。

## CSV新增列

在原25列末尾追加8列，前25列顺序不变：

|字段|含义|
|---|---|
|ring_stage|七阶段实际编号，0表示当前无细分阶段|
|ring_guide|实际控制补线编号，包括H期间保留的编号|
|ring_source|0普通路线N，1当前补线G，2短时保持H，3无效U，4强制直行T|
|ring_direction|1内侧为左、-1内侧为右；不是实时舵机方向，0为未锁定初始值|
|bridge_seen|保留S5外侧路口观测，0.24.0不再作为S6出口门控|
|bridge_passed|保留S5路口通过诊断，0.24.0不再作为S6出口门控|
|exit_armed|S6白带及有效补线连续确认完成，转入S7时置1|
|transition_frames|当前阶段转换确认计数；S7普通道路交接时为exit_road_frames，不是角度触发计数|

字段来自控制ISR本次实际状态，不取屏幕预览。所有列均为数值，导出仍做会话、条数与FNV-1a校验，电脑脚本兼容25/33列。1MiB、50Hz不变；单条56字节、18724条、剩32字节，约374.48秒（6分14秒）。旧48字节格式可保存7分17秒，这一容量不再适用于本版。

## S3锁定规则

1. 优先使用当前帧S3补线；原有同向S4候选接续规则保留。
2. 短暂失去候选时，仅保留此前在S3接受的同向G13/G14或G15/G16；不会继承S2、反向补线或普通岔路中线。
3. 使用已有RING_CORNER_HOLD_MS=120ms。从最近一次真实有效补线计时，连续漏检不会刷新保持期限。
4. 超过期限返回无效路线，来源U、G0，阶段仍为S3；由现有有效性/保护逻辑处理，不新增停车策略。C14关闭时不能将U理解为已经停车。
5. 当前补线恢复后可立即恢复G。原S4确认条件连续满足3张新图后正常转入S4，不锁死状态、不改出环门控。
