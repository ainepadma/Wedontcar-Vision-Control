# 本轮中线、误补线及环岛状态修复

工程位置：E:\Wedontcar-Vision-Control-1101-yubao；Downloads同名工程同步视觉源码。当前说明优先于之前两轮。

## 已定位原因

1. p1在旧逻辑中已算出普通中线，但H/?显示分支将其隐藏；360阶段3/4丢失V时也可把有效普通路径覆盖为invalid。
2. p9、p10有近端主赛道及大量有效行，仅因远端覆盖比例不足等组合条件导致整帧失效。单边救援只给转向数值、不生成逐行中线，也是空线来源。
3. p2在未确认环岛的S0预览中，无条件选取G17右侧候选，造成普通弯道被斜截断；p10的背景/弯道轮廓可同时满足旧A/P弱特征，误锁右环入口。
4. 阶段3可仅因V暂失加paired提前推进；候选补线无效时会在补线、普通线和invalid间变化。
5. p7阶段5/6使用的是最后一处行有效性转换bp，而不是显示的A尖角。

## 本次修改

- 保留普通视觉严格提取作为首选，补充主赛道白带恢复：从近端关联白带，接受触边急弯，跨局部黑色接缝继续观察延续段；不再仅因远端覆盖不足丢弃整帧。修复后逐行中线及偏差/航向同源，并用于实际循迹。
- 关联以已有有效主带为锚；远处隔离白条不重新作为主种子。保留足够的带宽、支持面积与近端覆盖，拒绝孤立近端白噪点；确实没有白色主赛道时不虚构路线。
- 无当前环岛候选时使用当前普通路径并保留环岛阶段/方向，不再使用过期中线或把主赛道置invalid。显示H/?也不再隐藏当前普通逐行中线。
- 删除冷态G17预览回退。入口P新增封闭黑色岛连通域验证，外侧背景/普通弯道黑块不能充当岛P；有界队列溢出保守拒绝入口，不越界或动态分配。
- 阶段3需真实、靠近车体的对侧V证据后才能推进，不再仅凭paired；在上一V位置附近用当前轮廓重找短暂漏检的V，支持入环补线稳定。重找点不作为新的事件票，也不被当作“已消失”，并限制连续重找寿命。
- 阶段5/6以真实A尖角作为右侧连接端点。A存在时不再受bp漏检影响；无真实尖角时不从任意行断点乱画蓝线。
- 本轮改动范围扩展到普通视觉中线恢复，已由用户明确确认。运动ISR、PID、舵机/差速控制、IMU、相机配置与当前速度参数没有修改。
