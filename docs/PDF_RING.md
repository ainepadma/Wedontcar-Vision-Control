# 本次环岛视觉替换说明

当前实现替换了运行时原 270/360 角点事件算法与旧 ZORE 残留，环岛入口在 track_ring_vision_process，几何在 ring_corner.c，状态选择在 ring_control.c。运动控制与 ISR 文件保持原压缩包内容。main.c 只修改视觉预览和叠加显示。

- 摄像头保持 304×154，显示保持 125×100。红色为观测边界，蓝色为补线，绿色为最终选中的循迹中线。停机预览以 P 标记，H 表示短暂沿用旧帧指导，? 表示图像与选择帧不一致。
- 270：移植 E:\八邻域_v2.0 的镜像八邻域寻边、边界提取与斜率/截距补线思路。坐标、计数和求和适配原生尺寸；原参考程序中潜在的负索引、8 位溢出没有直接照搬。到十字路口始终用同一套补线直行。状态只防止同一开口重复触发，入出口无须不同的转向策略。
- 360：PDF 第一节的七个有序阶段。A/P 与对侧连续边界确认入口；方向锁定；第一次出口继续绕行；再次出现出环几何后收尾。一次新图像最多推进一个阶段，重复帧不增加确认次数。图像在主循环内处理，中断只选择预计算结果。
- 按最后补充的红线图，阶段 5 的右侧出环缺口补线改为连接到真实上方横向边界，不再连接画面左上角。上端点在断口向内约四分之一近端路宽处向上搜索，要求连续三像素黑边支持；右环镜像。阶段 7 保留 PDF 的最后出环补线。
- 原图不写入补线。先修复私有边界，再计算中线，控制与屏幕使用相同 guide_id 的结果。所有 PD、速度 PI、舵机限幅、差速、IMU、编码器算法保持原样。
