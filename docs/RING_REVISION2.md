# 环岛视觉第二次修正

已确认的目标：360°按 p2 → p5 → p9 → p4；p2不改；p1仅补右侧横断处；270°十字按p8连接左右尖角，入口和出口使用相同直行逻辑。停机手推也连续预览。

## 改动

1. 270°改为检测两侧上下尖角并各自直接连接，G2不再是外推结果的副本。有证据的双侧路口优先于单侧360入口；上下尖角的向内白点必须属于近端连通赛道，隔着黑带的远处路口不能接管。
2. 关键点采用边界轮廓与行边界粗定位、局部转折和中值支持；轮廓A点不再被清空后直接丢弃。连续帧漏检时在当前帧局部重找四个尖角，检查各尖角的黑白象限支撑，再重新计算两条连接和中线，不把旧帧线冒充当前帧。
3. 360°第一次看到内侧V：连接V到右下边界转入。先经过配对道路、确认第一个V消失后，才允许第二次同类V触发出环：补内侧左边连接。不能因为第一个V停留在画面里就重复消费。
4. p1/p9右侧局部连接仅补右边，左边没有补线；最终p4出环才改补左边。这是两个不同阶段。
5. 增加独立屏幕预览状态，停机时每个采集帧推进同一视觉状态逻辑；手推不受行驶20秒期限约束，不调用运动tick。启动电机后显示真实行驶状态，预览不写真实环岛状态、控制邮箱或执行器。p2初始入口线的端点、偏差与航向保持逐值一致。
