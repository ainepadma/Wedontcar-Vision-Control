# Wedontcar-Vision-Control

智能车竞赛镜头组 RT1064 固件：MT9V034 图像采集、白色赛道识别、环岛补线、PD 转向与双轮 PI 调速。

当前源码版本 **0.26.0**（2026-11-06），基于用户指定的最新 Downloads 工程修复第三、第四次补线。删除按边界角度强制直行300ms；第三次保持实际右侧横口补线，第四次按左侧出口V点连接左下真实边界，以实际中线引导出环。尚未烧录，实车整圈效果待验证。

> 版本与验证记录见 [CHANGELOG](CHANGELOG.md)，视觉阶段与日志说明见 [环岛诊断](docs/RING_DIAGNOSTICS.md)。本地归档工程无 Git 元数据，本轮未提交、未推送。

## 当前算法与参数

### 图像与路线

- 摄像头配置304×154裁切窗口、2×2合并、50帧；`MT9V03X_AUTO_EXP_DEF=0`、`CAMERA_TUNING_EXPOSURE=1024U`，保持手动曝光。`MT9V03X_GAIN_DEF` 从 32 调至 64（驱动标注范围上限），`CAMERA_TUNING_AUTO_BLACK_LEVEL=1U`，初始化在设置曝光后写寄存器 `0x47=0x0080`。该写入返回值未检查，是否生效需硬件确认；不能把自动黑电平配置等同于自动曝光。屏幕、图传和算法使用同一双翻转方向。
- `image_track_preprocess_stable()`使用裁切后完整 `[0%, 100%)` 图像进行统计、滤波和二值化，不再叠加旧地面ROI。
- 预处理使用受限增益、4×3 分块局部补偿、按时间平滑的阈值参数、孤立噪点清理和小黑孔填充。白权重 42%、局部强度 50%、平滑时间常数 25 ms；仅保存参数，不沿用上一帧像素或中线。弱分离帧保留当前二值预览，但阈值诊断255表示控制观测无效。
- 预览不进行整图清黑或30%～68%关联遮罩；完整二值图显示后叠加诊断线，原始灰度图传仍提前冻结。
- 普通循迹ROI为裁切后 `[0%, 100%)`，304×154图像第0～153行都可参与。
- 路线关联从 `[66%, 100%)` 近端寻找种子，向上传播至图像顶部；断开的远处道路不重新作为种子。此为道路连通性判定，不是显示裁切或清黑。
- 普通视觉先运行严格提取；近端关联主白带仍可靠时，允许触边急弯、局部黑色接缝和部分远端覆盖不足的恢复。远处隔离白条不重新播种，孤立近端白块和全黑图不建立路线。最终逐行中线、误差和航向必须同源。详见第三轮修复说明。

### 转向与速度

- PD：`TRACK_STEER_KP=0.030`、`TRACK_STEER_KD=0.0005`；近场P最多增强40%。`TRACK_HEADING_WEIGHT=0.40`、`TRACK_APPROACH_HEADING_WEIGHT=0.05`，为用户本地已调参数，本次保留。普通道路近处直、远处弯时偏向0.05，同向弯进入近处后渐升到0.40；无近场几何或使用环岛补线时采用0.40。这两个权重不相乘，也不改变图像视野。
- 舵机右/中/左为75.5°/87.0°/98.5°，C30、50Hz；变化率180°/s，10ms最多1.8°。命令角不等于实测车轮角。
- 普通档直道初值120、弯道最低90计数/10ms。C15每次有效按下仅把RAM中的普通档直道目标加10，例120→130→140；长按不连加，C13停机再启动保留，重新初始化恢复宏值120，不写Flash。C15不再切换FULL档；253/145是保留的FULL配置值，不代表当前按键可切入。
- 速度PI为P=25、I=0.3、D=0，积分限12000；PWM上限7000（70%），不是固定运行占空比。目标缓升和原差速沿用；架空轮速换算不代表实测地速。

### 环岛路径与显示

- 270°检测左右上下尖角并同侧连接，入口和出口使用同一直行逻辑；有证据的双侧路口优先于单侧360入口，隔着黑带的远处十字拒绝接管。
- 360°使用七阶段顺序。S5维持第三次右侧横口补线；横口通过后S6等待内侧出口V，S7连接内侧V至同侧下方实际边界。每张新图最多推进一阶段，重复帧不计确认票。
- S3/S4的偏差、航向和显示中线仅统计补线顶点及下方的入环区域；有当前真实外侧V时可继续S4，确认期间允许有效同向G15接续。
- 第三次补线优先使用右侧横口实际内向尖角，沿用连接左上真实黑色边界的方法；第四次不依赖全宽白带或固定60°角。保留正常道路稳定交接和重入冷却。
- 红色为观测边界、蓝色为补线、绿色为最终中线；P为独立停机手推预览，H为旧指导保持，?为帧不匹配。停机预览不写真实行驶状态或执行器；当前普通中线不会仅被H/?显示分支隐藏。

### 按键与保护

| 按键 | 当前功能 |
| --- | --- |
| C12 | 显示/USB图传开关 |
| C13 | 启动/停止；停机不会清除C15的RAM直道目标 |
| C14 | 视觉丢线、停帧、未就绪及环岛故障停车保护，默认关闭 |
| C15 / KEY_1 | 普通档直道目标每次有效按下+10；舵机标定调试模式为独立例外 |

C14关闭不取消编码器反号、无反馈或超速停机保护；本轮没有改变这些阈值。自动停车在清零PWM前记录原因/轮号/保护/计数/目标/PWM/时间，屏幕LAST与USB `LSSEQ/LST/LSREASON/LSW/LSP/LSL/LSR/LSTARGET10/LSLPWM/LSRPWM`保留最近事件，C13重启不擦除，下电清空。原因8环岛故障现在保留正确分类。没有现场停车读数时不能确定实际触发原因。

## 360入口试验参数（0.22.3）

在 `demo/user/inc/ring_corner.h` 调整：

- `RING_ENTRY_REQUIRE_CLOSED_ISLAND`：当前0，允许黑块触碰画面边缘；1恢复完全封闭要求。最小面积、高度和8192像素容量检查始终保留。
- `RING_ENTRY_AP_MIN_GAP_PERCENT`：当前10，降低会允许更小的A/P上下间距。
- `RING_ENTRY_AP_MAX_GAP_PERCENT`：当前100，降低会排除更大的上下间距。
