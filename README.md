# Wedontcar-Vision-Control

当前 **0.28.0**，2026-11-07，分支 `1106-deng`，提交标题 **最终刹车和补线**。C盘当前补线和正常运动算法为主，合入E盘七条纹刹车。第三状态左倾0.06，原始角点旋转和平行中线保留。
普通档直道/弯道最低目标 `90/70` 计数/10ms；尚未烧录、未做实车整圈验收。

## 当前算法与交付

- 先读 [CHANGELOG](CHANGELOG.md)、[SUMMARY](SUMMARY.md)、[环岛诊断](docs/RING_DIAGNOSTICS.md)、[刹车说明](docs/STRIPE_BRAKE.md)。历史专项文档保留原始证据，不代表当前测试通过。
- 270°入口/出口双侧尖角连接；360°按内部S1～S7推进。第三次为S5/S6，白横带当帧只记录分隔，后续新帧向下V/直角才进入第四次S7。300ms强制直行、固定60°出口规则已经删除。
- 第三状态以当前黑角为旋转点，左倾系数0.06；固定宽度1/6屋顶探测，中线向内平移0.30w并与补线平行，补线外侧原边线不参与控制。
- 七条纹连续三个可靠新帧准备；单帧到位锁停，保留裁切大小证据。无需C13、独立于C14；双轮位置保持和舵机冻结，C13不能解除，复位/重新上电清除。原因9=STRIPE。
- 正常行驶PI、转向PD、差速和加速斜坡保持来源工程；P/D=0.030/0.0005，航向权重0.40/接近0.05，舵机180°/s，中位87°及原端点不变。C15每次有效按下普通直道目标+10，长按不连加，复位恢复宏值；FULL253/145保留但C15不切档。
- C14视觉/环岛保护默认关；反号、无反馈、超速保护独立有效。条纹主动锁停另见[停车诊断](docs/STOP_DIAGNOSTICS.md)，日志PWM为幅值，不能从CSV推断DIR正负。

## 工程与数据流

CSI帧→双翻转和原预处理→普通/环岛识别与独立条纹检测→同帧邮箱→10ms控制中断→原PD/双轮PI；条纹锁停后由独立位置保持分支接管。
补线不涂改原始二值图。`track_stripe_brake.c/.h`负责检测/锁存/保持；`isr.c`接入执行器和按钮；其余视觉/控制职责不变。

用Keil打开 `demo/mdk/rt1064.uvprojx`，目标 `nor_sdram_zf_dtcm`。已编译固件在本地 `firmware/rt1064.axf`，默认下载副本在 `demo/mdk/Objects/rt1064.axf`；构建输出不新增入Git。IAR未验证；其工程尚未接入刹车源文件，不声称可直接构建。版本输出 `#CAM/#SPD/#LOG FW=0.28.0`。

## 验证和下一步

本次实际主机/编译结果逐项记录在[验收记录](docs/RELEASE_CHECKS_0.28.md)和CHANGELOG；安全执行入口为 `python tools/run_host_checks.py`；历史失败不算通过。优先处理[待测试](待测试.md)中的环内乱线/中线消失和右环岛独立流程建议。本轮不修改这些待办对应的算法，不连接车辆、不烧录、不启动电机。
