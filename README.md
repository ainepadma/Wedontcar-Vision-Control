# Wedontcar-Vision-Control

本项目为智能车竞赛镜头组项目，用于记录和开发本队的视觉循迹与车辆控制代码。

## 项目背景

本队参赛组别为镜头组。车辆的底盘与控制硬件以校内上一组电磁组的方案为基础，计划使用与其相同的配件；当前已经确认的核心器件为：

- 主控：RT1064
- 其他配件：待补充

由于参赛组别不同，本项目将拆除原方案中的电磁相关组件，改用总钻风 MT9V034 120°镜头完成赛道图像采集。后续需要在原有车辆控制代码的基础上，重新实现并调试视觉识别、路径提取和转向控制等功能。

## 目录说明

### `.dist`

`.dist` 中保存的是上一组电磁组参加校赛并获得一等奖时留下的三个最终代码版本：

- `FINAL 22.09 NO 1`
- `FINAL 23.14 NO 2`
- `FINAL 23.36 NO 3`

这些代码主要用于参考上一组车辆的 RT1064 工程配置、底层驱动、电机与舵机控制、编码器测速、PID 控制及整车控制流程。由于其中的赛道感知逻辑基于电磁传感器，不能直接作为本镜头组的最终方案使用。

### `.reference`

`.reference` 中保存的是浙江省镜头组开源代码。该代码使用的主板与本项目不同，因此仅用于参考其图像采集、视觉处理和镜头组控制思路，不能直接编译或烧录到本项目的 RT1064 主板。

### `DEMO` 与 `libraries`

`DEMO` 和 `libraries` 是当前 RT1064 工程及其依赖库所在目录。后续开发应在确认硬件接线、工程配置和代码来源后进行，并逐步将适用于本车的底层控制与镜头组视觉功能整合到当前工程中。

## 当前改造方向

1. 核对并补充完整配件清单和引脚连接关系。
2. 保留能够复用的电机、舵机、编码器、PID及底层驱动代码。
3. 拆除电磁传感器及其信号采集、赛道判断代码。
4. 接入总钻风 MT9V034 120°镜头。
5. 根据本车主板和赛道要求移植、实现并调试视觉循迹算法。

## 注意事项

- `.dist` 和 `.reference` 均为参考资料，应保留原始内容，避免直接修改。
- 不同主板之间的时钟、引脚、外设驱动和烧录配置可能不同，参考代码不能未经移植直接使用。
- PID参数、舵机中值、速度参数和视觉阈值均需根据本车实际硬件重新标定。
